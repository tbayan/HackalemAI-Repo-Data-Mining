# HackAlem AI 2026: 3 649 репо не айтады?

**Автор:** Dr. Talgar Bayan · **Күні:** 24.09.2026 · **Дерек:** [BAITC-Hacks](https://github.com/BAITC-Hacks) ұйымының ашық GitHub реполары

> **Ескерту.** Барлық дерек ашық (public) GitHub реполарынан алынды. Қатысушылардың жеке деректері талданған жоқ және бұл репода жарияланбайды: мұнда тек жиынтық сандар мен графиктер бар. Бұл хакатонның ресми нәтижесі емес. Толығырақ: [7-бөлім](#7-ескерту).

## Қысқаша

- Тіркелген әр командаға GitHub-та автоматты түрде репо ашылды: барлығы **3 649 репо**.
- **2 383 репо (65,3%) бос:** онда бірде-бір командалық коммит жоқ.
- **1 057 репода (29,0%)** жарыс уақытында (13:00–18:00) коммит бар.
- Ең қызу сағат соңғысы болды: **17:00–18:00 аралығында 7 867 коммит**. 18:00-де белсенділік күрт тоқтады.
- Жарыс уақытында коммит жасаған командалардың **79%-ы** бес сағаттың кемінде төртеуінде коммит жасады.
- 12 кейстің ең көп таңдалғаны: **AI Sana білім беру кейсі (145 команда)**. Ең азы: **Halyk Bank «Voice Router» (29)**.

## 2. Реполар мен коммиттер

### 2.1. Әр үш репоның екеуі бос қалды

![3 649 репоның қаншасында код жазылды?](charts/bilingual/01_funnel.png)

3 649 репоның 2 383-інде (65,3%) бірде-бір командалық коммит жоқ. Кемінде бір коммит 1 266 репода бар. Жарыс уақытында (13:00–18:00) коммит жасалған репо 1 057 (29,0%). Тағы 209 репода коммит бар, бірақ олар жарыс басталғанға дейін жасалған. Жарыс уақытында коммит жасалған реполардың 984-і (93,1%) 12 кейстің біріне сәйкестендірілді.

**Бос репо «жалқау команда» дегенді білдірмейді.** 6 586 өтінімге 2 500-ақ орын болды, кейбір адамдар кезекте тұрып, ішке кіре алмады. Кейбір командалар бірнеше рет тіркелген сияқты: 225 команда атауы бірнеше репода қайталанады. Дерек бұл себептерді бір-бірінен ажырата алмайды.

### 2.2. Коммит деңгейлері

![Әр репоға қанша коммит түсті?](charts/bilingual/02_commit_levels.png)

Коммиті бар реполар арасында ең жиі кездесетін деңгей — 21–50 коммит (364 репо). 100-ден көп коммит 30 репода бар. Кемінде бір коммиті бар репоның медианасы — 16 коммит. Санауға барлық тармақ кіреді, автоматты ашылған алғашқы коммит есептелмейді.

## 5. Әдістеме

1. **Реполар.** BAITC-Hacks ұйымындағы барлық репо тізімі GitHub REST API арқылы алынды: 3 649 репо, бәрі архивтелген (`src/fetch_repos.py`). Деректер 24.09.2026 түнде жиналды.
2. **Коммиттер.** Әр репоның main тармағындағы коммит саны (`src/fetch_commit_counts.py`) және коммит уақыты (`src/fetch_commit_timings.py`, бір репоға ең көбі 300 коммит) GitHub GraphQL арқылы алынды.
3. **README.** 3 644 README raw.githubusercontent.com арқылы жүктелді (`src/fetch_readmes.py`); 5 репода README жоқ.
4. **Репо кестесі.** `hackalem_repos_analysis.csv` кестесінде әр репо бойынша командалық коммит (барлық тармақ, автоматты алғашқы коммитсіз), 13:00–18:00 аралығындағы коммит, коммит болған сағат саны және кейс белгісі бар. Кесте бөлек жасалған, оны құрған скрипт әзірге осы репода жоқ. Біз оны API деректерімен салыстырдық: 1 057 белсенді репоның 991-інде коммит болған сағат саны main тармағы бойынша өз есебімізбен дәл сәйкес келеді, қалғанында кестедегі мән жоғары, бұл басқа тармақтардағы коммиттерге сәйкес.
5. **Кейс.** Кейс белгілерін README мәтіндерімен кілтсөз арқылы салыстырдық. Сәйкес келмегендерін қолмен оқып, 7 қате белгіні түзеттік (`CASE_FIXES`, `src/plot_bilingual_charts.py`).
6. **Уақыт.** Барлық уақыт — Астана уақыты (UTC+5).
7. **Сандар.** Графиктердегі және осы README-дегі сандарды `src/plot_bilingual_charts.py` есептейді және `charts/bilingual/facts.json` файлына жазады.

## 6. Шектеулер

- Бір репо — бір тіркелу (команда), адам емес. Командада үш адамға дейін болды, сондықтан адам санын бұл деректен анықтау мүмкін емес.
- Бос репоның себебін дерек айтпайды: команда келмеген, ішке кіре алмаған, қайта тіркелген немесе кодты басқа жерде жазған болуы мүмкін.
- Коммит саны жұмыстың сапасын да, көлемін де өлшемейді.
- README-і автоматты үлгі күйінде қалған 19 репоның кейс белгісі тексерілмеді.
- Уақыт графигі тек main тармағына негізделген; екі репода 300-ден көп коммит бар, олардың артығы графикке кірмеді.

## 7. Ескерту

- Барлық дерек BAITC-Hacks ұйымының **ашық (public)** GitHub реполарынан алынды. Жабық жүйеге кіру болған жоқ.
- Қатысушылардың жеке деректері (аты-жөні, email, телефон, коммит авторлары) талданған жоқ және бұл репода **жарияланбайды**. Репода тек жиынтық сандар, графиктер және код бар. Жиналған шикі деректер (`data/`) жарияланбайды.
- Бұл автордың жеке талдауы, **хакатонның ресми нәтижесі емес**. Жеңімпаздарды қазылар алқасы анықтайды.

## 8. Қайта жасау

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env              # GITHUB_TOKEN=...
cd src
python fetch_repos.py             # data/repos.csv
python fetch_commit_counts.py     # data/commit_counts.csv
python fetch_commit_timings.py    # data/commit_timestamps.csv
python fetch_readmes.py           # data/readmes/
python plot_bilingual_charts.py   # charts/bilingual/*.png + facts.json
```

`data/` папкасы репоға қосылмаған, сондықтан деректерді жоғарыдағы скрипттермен ашық реполардан қайта жинау керек. Соңғы қадамға `hackalem_repos_analysis.csv` кестесі де керек (5-бөлімнің 4-тармағын қараңыз). Графиктерге қазақ әріптері бар қаріп керек (Noto Sans немесе DejaVu Sans).
